# Visual sources

Brand and copy: existing v.build portfolio source, reviewed 2026-09-21. Only selected public-facing project descriptions are reproduced. No private project source code is included.

`assets/banner-v1.png`: 2172 × 724 PNG, generated with the built-in ImageGen tool. Reference: the portfolio's original `avatar-head-v1.png`. The generated banner was visually inspected for complete hair/chin, recognizable glasses and face, exact brand spelling and readable typography. It is a newly generated interpretation, not a pixel-identical copy of the original head.

Generation prompt:

> Create a clean editorial horizontal GitHub banner for v.build. Use the original mascot as the identity reference: black layered hair, rectangular black glasses, brown eyes, warm skin. Place one complete head in the right third, yellow and red square brackets, white background, orange edge accent. Leave left space for typography. No gradients, dots, pulses, circuits, glow, gadgets or watermark. Keep all hair and the chin.

Refinement prompt:

> Preserve the mascot and bracket composition. Add exact typography in the left area: “VADIM BEDNOV / DEVELOPER”, “v.build”, “From idea to” and “a working product.” Add the portfolio's green slash. No additional copy or decoration. Keep generous margins and the wide 3:1 ratio.

Buttons and activity graphic are code-native SVGs, not generated raster images. Their copy, colors, geometry and activity data are deterministic. The poster is decorative; its essential meaning is also available as normal README text and alt text.

Project entries link directly to their public demos; no private source or unfinished placeholder covers are copied. All artwork is project-specific; no general reuse licence is granted here.
