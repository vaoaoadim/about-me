# Промпт: GitHub-профиль v.build

Оформи GitHub-профиль `vaoaoadim` как портфолио независимого разработчика v.build для потенциальных заказчиков. Источник фактов — актуальный сайт. Не придумывай клиентов, достижения, отзывы, стаж и показатели.

## Содержание

Создай публичный профильный репозиторий `vaoaoadim/vaoaoadim`. Подготовь английскую и русскую версии: позиционирование «Из идеи — в работающий продукт», услуги, избранные проекты, рабочий стек и понятный способ обсудить заказ. Подчеркни разработку полного продукта, поддержку и FAQ при передаче. Включи только настоящие кейсы: ХОЧЕЦА, BeautyBomb Delivery и Pläner. Обозначь BeautyBomb как независимый портфолио-концепт.

## Визуальный язык

Сохрани стиль сайта: чистая композиция, чёрно-белая основа, зелёный `#23ad64`, жёлтый `#efc331`, красный `#ef4c46`, оранжевый `#fb7b2d`, квадратные скобки и оригинальный маскот. Создай согласованный постер без случайных украшений, точечных паттернов и перегруженных эффектов. Не меняй внешность персонажа.

## Интерактивность

Добавь цветные кнопки Telegram, email и перехода к проектам. Используй только подтверждённые ссылки. Сайт пока находится в разработке на Sites и закрыт для гостей: не публикуй его и не добавляй неработающую публичную ссылку. Для Instagram и Threads нет подтверждённых URL — не придумывай их.

Используй возможности GitHub README: ссылки, раскрывающиеся блоки и совместимые изображения. Не обещай исполняемый JavaScript или произвольный веб-интерфейс в README.

Создай отдельную анимированную визуализацию настоящего публичного календаря contributions. Обновляй её ежедневно, учитывай reduced motion. Не изменяй штатный календарь GitHub, не создавай фиктивную активность и не раскрывай приватные проекты. Служебные обновления публикуй от GitHub Actions в отдельную ветку.

## Приёмка

Проверь ссылки, изображения, оба языка и читаемость на узком экране. Анимация не должна изменять фактические уровни активности. Ошибка загрузки данных не должна заменять рабочий график пустым. Публикуй только профиль и его собственные материалы, не изменяя исходники сайта и приватность других репозиториев. Верни ссылку на профиль и ограничения.
